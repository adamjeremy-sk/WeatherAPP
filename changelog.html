About This Changelog

Every public release of WeatherAPP Libre is listed below, newest first. Each entry is grouped by the type of change:

  • Added — new features and capabilities.
  • Changed — adjustments to existing behaviour or layout.
  • Fixed — corrections to defects, alignment, and stability issues.

Version numbers are followed by a VC## suffix denoting the internal Android version code for that release.

0.6.4VC24 Latest

Released October 17, 2026

Changed

  • Cache TTL Alignment: Reduced the default weather cache time-to-live from 120 minutes to 60 minutes, synchronizing it perfectly with the WorkManager polling interval and XML update period.

Fixed & Improved

  • Widget Clipping Fix: Tightened the vertical height budget across all three widget layouts (2x1, 4x1, 4x2) by reducing root padding to 4dp, shrinking margins to 2dp, and capping the 4x2 temperature height at 48dp, eliminating layout clipping on constrained third-party and OEM launchers like Niagara and Xiaomi.
  • Widget Sync Invalidation Trigger: Bridged the cache-write to widget-read disconnect by adding an immediate invalidation trigger in the WeatherRepository. Whenever the main app successfully writes fresh data to the persistent cache, all active widget instances are now enumerated, synchronously rebuilt, and forced to redraw instantly, permanently eliminating the stale "--" temperature fallback state.

0.6.3VC23

Released October 16, 2026

Changed

  • Theme Engine Modularization: Extracted BoutiqueThemeEngine and ColorPalette into a standalone, portable Android Library module (theme-engine) for reuse across projects. The module exposes a single public surface via ThemeMode constants and getPalette(), with zero coupling to host-app business logic. Legacy Fire Engine installs continue to self-heal to the Dark theme via the host app's migration resolver.
  • Widget Information Architecture Overhaul: Restructured all three widget footprints for clarity and consistency. Removed the redundant city name from all layouts (the selected tab pill already displays it). Sunrise/sunset now render universally as locale-neutral arrows (↑/↓) on all layouts. Moonrise/moonset moved to the right column on 4x1 and 4x2 with localized labels. The 4x2 middle timings row narrowed to Transit and Nadir only; the feature panel (Night Visibility, Solunar Activity, True Dark Sky) now expands to fill available height.
  • 2x1 Widget Conversion: Converted the small widget from a 2x2 quadrant grid to a compact 2x1 two-column stack, removing the pill bar to fit within one-cell height grants on tight launchers. Left column carries the solar narrative (icon, sun arrows, condition, high/low); right column carries the lunar narrative (hero temperature, moon arrows, moon phase name, night context, illumination). Increased icon size to 32dp and temperature autosize ceiling to 30sp for improved visual presence.

Fixed & Improved

  • 4x1 Alignment Fix: Resolved horizontal centering drift on the 4x1 temperature by restructuring the content row into three equal-weight regions (left data, hero temp, right data), ensuring the temperature renders on the exact centerline across all launcher implementations.

0.6.2VC22

Released October 15, 2026

Added

  • Home Screen Widgets: Added 4x2, 4x1, and 2x2 widgets with on-widget location tab pills, tap-to-deep-link into the app, Material You dynamic theming, sunrise/sunset rows, active natural light period display, and optional Night Visibility / Solunar Activity lines.

Changed

  • Widget Efficiency: Cache-first background sync via WorkManager with an adjustable 60-minute TTL; widgets refresh immediately on in-app tab edits and on app launch; no GPS and no independent network polling.
  • Edge-to-edge API 35+ Compliant: Removed deprecated status/navigation bar coloring and theme attributes; added theme-aware system bar icon contrast via SystemBarContrastHelper; full window inset coverage across all Activities and full-screen dialogs; purged legacy window flags and opt-outs.
  • Reorganized Theme Page: Regrouped the picker into Light Themes (Light, Crema, Frost, Orange Grove, Terracotta) and Dark Themes (Dark, Aurora, Charcoal, Cobalt, Jade) with simplified display names in English and French.
  • Removed Fire Engine Theme: Deleted with a self-healing migration that moves legacy installs to the Dark theme; all special-case branches purged from drawers, headers, dialogs, and night-mode mapping.
  • Removed Syzygy: Badge, data flag, and strings removed from the Lunar Calendar as redundant (occurs at every New and Full Moon); the term remains documented in the Lunar Almanac glossary.

Fixed & Improved

  • French Localization Fixes: Externalized all remaining hardcoded English strings (weather conditions, moon phases, sub-tab and menu labels, natural light phases, night visibility and solunar labels, forecast model and theme descriptions); enforced French typography (space before colons); localized dropdown menu entries and dialog buttons.

0.6.1VC21

Released October 14, 2026

Added

  • Lunar Calendar UI Overhaul: Replaced bottom sheets with a compact, inline week-by-week layout (Sunday–Saturday) featuring inline cell expansion for exhaustive lunar details.
  • Long-Term Caching: Added a 3-year forward-looking lunar event cache generator with a progress bar and warning dialog, enabling instant loading of the "Special Lunar Events" filter.
  • Atmospheric Phenomena Heuristics: Integrated probability calculations for Lunar Moonbows, Halos, Coronas, and Parselenes, now displayed in the main Moon Phase popup and 7-day forecast expanded views (including explicit "Unlikely" messaging when conditions are unfavorable).
  • Enhanced Event Badging: Added dedicated badges for Penumbral, Partial, and Total eclipses, as well as Micromoons and Syzygy.

Changed

  • Performance Optimization: Implemented a 30ms debounce delay combined with user-configurable volume scroll speeds to prevent CPU lag during rapid date cycling.
  • Vector Icon Correction: Swapped and corrected the path data for ic_moon_new.xml and ic_moon_full.xml to accurately represent their respective lunar phases.
  • Theming & Navigation Fixes: Replaced the native DatePickerDialog with MaterialDatePicker to ensure instant, dynamic theme color updates without requiring an app restart. Removed redundant calendar navigation buttons.
  • Settings Cleanup: Resolved the duplicate "Speed 1" entry in the Volume Key Date Cycling settings, enforcing a strict 1–7 sequence with improved, localized descriptions.
  • Date Formatting: Ensured the year is explicitly displayed in the Special Events view to prevent ambiguity across the 3-year forecast range.

Fixed & Improved

  • Highlighting Parity: Fixed the "Today" cell highlighting in the Lunar Calendar to use solid, opaque colors, perfectly matching the visual rendering of the 7-day and hourly forecasts.
  • Fixed Syzygy badge contrast for universal theme visibility.
  • Mathematical Verification: Audited and confirmed the Blood Moon (Total Lunar Eclipse) calculation logic strictly adheres
