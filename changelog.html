About This Changelog

Every public release of WeatherAPP Libre is listed below, newest first. Each entry is grouped by the type of change:

  • Added — new features and capabilities.
  • Changed — adjustments to existing behaviour or layout.
  • Fixed — corrections to defects, alignment, and stability issues.

Version numbers are followed by a VC## suffix denoting the internal Android version code for that release.

0.5.1VC17 Latest

Released October 8, 2026

Added

  • Option to move the 7-day forecast into the drop-down menu.
  • Toggle to choose whether the 7-day forecast appears in the menu or inline below Current Weather and Hourly Forecast.
  • Menu Organization screen for reordering drop-down menu pages by dragging.
  • Ability to set the default page shown on launch.
  • Ability to enable or disable individual pages in the drop-down menu.

Fixed & Improved

  • Current Weather title now displays correctly on launch.
  • Fixed when the 7-day forecast is displayed.
  • Corrected the True Dark Sky window icons.
  • Night Visibility Forecast now highlights the current stage of the night.

0.5.0VC16

Released October 7, 2026

Added

  • True Dark Sky, Night Visibility, and Solunar Activity forecasts.

0.4.8VC15

Released October 7, 2026

Added

  • Alert log history.

Fixed & Improved

  • Cleaned and hardened the compilation test suite.

0.4.7VC14

Released October 6, 2026

Added

  • "Feels like" temperature.
  • Long-press on a location tab to open the location chooser.

Changed

  • Initial startup no longer requests a location full-screen.
  • Menu layout refreshed.

Fixed & Improved

  • Text alignment in main page cells.
  • Back button now returns to the main weather view.
  • Repeated notification permission prompts on every update.
  • Alignment in the 7-day forecast.
