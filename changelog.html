About This Changelog

Every public release of WeatherAPP Libre is listed below, newest first. Each entry is grouped by the type of change:

  • Added — new features and capabilities.
  • Changed — adjustments to existing behaviour or layout.
  • Fixed — corrections to defects, alignment, and stability issues.

Version numbers are followed by a VC## suffix denoting the internal Android version code for that release.

0.6.0VC19 Latest

Released October 13, 2026

Added

  • Published the complete application source code under the GNU GPLv3, ensuring long-term transparency and privacy guarantees.
  • Added a comprehensive automated test suite (137 tests) guaranteeing mathematical rigor and numerical stability for the astronomical engines across millennia.

Changed

  • Completely overhauled the solar and lunar calculation engines (17-module remediation). Replaced truncated Delta T polynomials with official Espenak/Meeus tables for almanac-grade accuracy.
  • Upgraded topocentric converters to use atan2 for perfect numerical stability at extreme latitudes (including the North and South Poles).
  • Integrated exact geometric horizon dip calculations, ensuring accurate sunrise/sunset times for high-altitude observers.
  • Rebuilt the solar timeline engine to dynamically bridge missing twilight phases, gracefully handling Midnight Sun and Polar Night edge cases without UI placeholders.

Fixed & Improved

  • Corrected atmospheric refraction frames to properly account for the apparent upper limb crossing the horizon, eliminating multi-minute sunrise/sunset errors.
  • Eradicated negative-epoch truncation bugs, ensuring flawless astronomical calculations for dates prior to 1970.
  • Removed excessive debug logging in the moon rise/set solver, eliminating severe UI stuttering and battery drain during 7-day forecast generation.
  • Renamed the mislabeled "7-Day Forecast Placement" settings cell to accurately reflect "Location Tabs" management.
  • Removed the redundant Default Location cell from the System settings menu.
  • 7-day forecast now correctly displays wind direction alongside wind speed.
  • Improved text contrast in the location search dialog across all dark and boutique themes.
