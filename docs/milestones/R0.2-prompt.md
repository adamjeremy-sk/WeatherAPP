Keys are paths relative to `root` with `/` separators.
- `fun compare(expected: Map<String, String>, actual: Map<String, String>): List<String>`: `expected` is the manifest, `actual` the tree. Returns violations sorted by path, each exactly `"CHANGED <path>"` (in both, hashes differ), `"MISSING <path>"` (in the manifest, not on disk) or `"UNEXPECTED <path>"` (on disk, not in the manifest). Empty list means equal.

1.3 `SizeBaseline.kt` — the file-size ratchet: parse, measure, compare. Contract:
- `const val BASELINE_PATH = "config/size-baseline.txt"`, `const val MAIN_LIMIT = 500`, `const val TEST_LIMIT = 800`.
- `fun parse(text: String): Map<String, Int>`: lines of the form `<count> <path>` (one space). Blank lines and lines starting with `#` are ignored. A malformed line or a duplicate path throws `IllegalArgumentException` whose message contains `line <n>`.

Return only the files over their limit: path contains `/src/main/` → limit `MAIN_LIMIT`; path contains `/src/test/` or `/src/androidTest/` → limit `TEST_LIMIT`; any other source set is ignored. Over means strictly greater than the limit. Keys relative to `root`, `/` separators.
- `fun compare(baseline: Map<String, Int>, over: Map<String, Int>): List<String>`: returns violations sorted by path: `"NEW <path> <lines>"` (over the limit, not in the baseline), `"GREW <path> <lines> > <baselineLines>"` (more lines than the baseline allows), `"STALE <path>"` (in the baseline, but missing or no longer over the limit; the entry must be removed).
