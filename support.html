1. Beta Program, Bug Reports & Support

Use this form to:

  • Apply for the WeatherAPP beta program
  • Report bugs and crashes
  • Request new features
  • Receive technical support
  • Ask privacy-related questions

All submissions are sent through your default email application.

For bug reports, please include: device model, Android version, WeatherAPP version, and steps to reproduce the issue.

2. Help & Support

To help resolve issues quickly, please include as many details as possible.

  • Device model
  • Android version
  • WeatherAPP version
  • Steps to reproduce the issue
  • Screenshots (if available)

Feature requests are welcome and help guide future development.

3. Privacy Notice

Please do not submit passwords, payment information, home addresses, or any other sensitive personal information.

For complete information regarding how WeatherAPP handles data, please review the Privacy Policy.
