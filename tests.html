Suite Overview

Following a comprehensive 17-module almanac-grade remediation, the WeatherAPP Libre astronomical engine is guarded by an exhaustive suite of deterministic unit tests. These tests verify official Espenak/Meeus Delta T polynomials, topocentric parallax, atmospheric refraction frames, horizon dip geometry, and polar edge cases across millennia.

Every test listed below executes automatically on every code commit, ensuring that the physics and mathematics governing your sunrise, sunset, and moon phase calculations remain strictly accurate and completely free of regressions. Click the Expand All Tests button in any section below to reveal the technical details of each specific validation.

1. General & Manager Integration

This section validates the high-level orchestration of astronomical data across the application's core managers. These tests ensure that complex, multi-day calculations for dark sky windows, night visibility, and solunar activity are mathematically deterministic and globally robust. By simulating diverse environments—from the equator to the Arctic Circle during midnight sun—these tests prevent edge-case crashes that could occur at extreme latitudes. The integration of mock cloud cover data ensures that the Night Visibility manager accurately attenuates ambient light based on real-world weather conditions. Furthermore, these tests guarantee that the 7-day solunar forecasts and dark sky summaries generate complete, gap-free datasets for the user interface. Without this layer of orchestration testing, individual calculation engines might pass in isolation but fail when chained together for weekly planning. Ultimately, this suite acts as the final quality gate before astronomical data is handed off to the UI layer. It ensures that photographers, anglers, and stargazers receive reliable, actionable planning data regardless of their geographic location.

2. Navigation & UI Tests

The user interface of a weather application must be both highly responsive and deeply customizable, which requires rigorous state-management testing. This section covers the complex logic behind menu organization, tab resolution, back-navigation interception, and preference migrations. When users customize their drop-down menus or set default launch pages, these tests verify that SharedPreferences round-trips are exact and that Activity recreation restores the correct state. The DayForecastAdapter and HourlyMapper tests are critical for ensuring that raw API streams are correctly sliced into 36-hour windows, properly handling Daylight Saving Time transitions and null data gaps. Additionally, the FeelsLikeHero and UnitUtils tests enforce strict precision parity between Metric and US Customary formatting, preventing visual discrepancies in temperature and wind gust displays. First-launch seeding tests guarantee that new users are immediately greeted with valid, pre-configured locations rather than an empty screen. By locking down these UI predicates and formatting utilities, this suite ensures a frictionless, polished experience across all Android form factors. It transforms raw meteorological data into a beautifully formatted, highly interactive dashboard.

3. Weather Alerts System

Delivering official, life-saving weather alerts requires absolute fidelity to government data standards and strict adherence to user privacy. This test suite validates the entire Environment and Climate Change Canada (ECCC) CAP-CP pipeline, from raw XML parsing to geographic polygon matching. The CapXmlParser tests ensure that multi-language alerts are correctly extracted, while the AlertMatcher tests verify complex ray-casting point-in-polygon geometry to accurately determine if a user's specific coordinate falls within a warning zone. Crucially, the AlertConsent tests enforce the application's privacy-first mandate, ensuring that alerts are never processed or displayed until the user has explicitly opted in via a transparent consent prompt. The caching and notification intent tests guarantee that expired alerts are pruned, duplicate notifications are suppressed, and tapping an alert correctly routes the user to the affected location tab. Unlike many weather apps that generate synthetic, model-derived warnings, this suite strictly enforces a zero-tolerance policy for fake alerts. This rigorous validation ensures that the background WorkManager reliably polls for updates without draining the device battery. Ultimately, when a tornado or severe thunderstorm warning reaches a user's device, it is guaranteed to be an authentic, geographically precise, and officially sanctioned government directive.

4. Lunar Astronomy Engine

Calculating the precise position and phase of the Moon requires solving complex orbital mechanics that have been refined over centuries of astronomical observation. This engine is built upon the foundational algorithms published in Jean Meeus's seminal work, Astronomical Algorithms, and validated against NASA's Espenak/Meeus Delta T polynomials. The tests in this section verify the conversion between Terrestrial Time and Universal Time, ensuring that the gradual slowing of Earth's rotation is accurately accounted for across millennia. The AtmosphericRefraction tests enforce the physical boundaries of the Bennett formula, preventing asymptotic divergence when celestial bodies dip below the horizon. Topocentric conversion tests, utilizing atan2 for numerical stability, guarantee that parallax and horizon dip are correctly applied for observers at extreme elevations or the North Pole. The MoonPhaseCalculator tests validate the Meeus Chapter 49 planetary perturbation corrections, ensuring that quarter-phase timings are accurate to the minute. By enforcing strict semantic boundaries between exact astronomical events and continuous phase categories, this suite prevents UI mislabeling. Ultimately, these tests transform abstract trigonometric series into the highly accurate moonrise, moonset, and illumination data that drives the app's astrophotography tools.

5. Solar Astronomy Engine

The solar engine is responsible for mapping the Sun's apparent journey across the sky, a task complicated by atmospheric refraction, axial tilt, and the observer's specific horizon geometry. This test suite rigorously validates the Brent-Dekker root-finding algorithm used to pinpoint the exact second the Sun's upper limb crosses the horizon. The SolarRiseSetSolver tests specifically enforce the use of apparent, refracted altitude rather than true geometric altitude, correcting a common physics error that would otherwise cause sunrise and sunset times to be off by several minutes. The SolarLightingEngine tests verify the dynamic generation of chronological timelines, ensuring that high-latitude edge cases like the Midnight Sun gracefully collapse into continuous states without generating UI placeholders. Regression tests, such as the full 365-day sweep for Saskatoon, Tromsø, and Wellington, prove the mathematical mirror symmetry between morning and evening twilight phases. The SolarPositionEngine tests validate the Meeus Chapter 25 solar longitude calculations and the exact geometric horizon dip formula for high-altitude observers. By strictly bounding the Bennett refraction formula and utilizing atan2 for topocentric stability, this suite ensures absolute physical rigor. This engine provides the foundational sunlight data that powers the app's Golden Hour, Blue Hour, and True Dark Sky planning features.
